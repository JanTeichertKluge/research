Introduction & Motivation

  • The Long-Term Problem in Digital Platforms
    • Randomized Controlled Trials (RCTs) can cleanly identify short-term impacts
    • But: Experiments are often too short to capture long-term outcomes of ultimate interest
      • Customer retention, lifetime value, future engagement
  • The Abundance of Proxies
    • Modern digital platforms observe many short-term metrics:
      • Clicks, page views, add-to-cart events, session durations, …
    • Question: How to use these to estimate long-term treatment effects?
  • Classic Surrogate Methods
    • Assume a single/few proxies that fully mediate long-run effects
    • Often implausible in practice!

Introduction & Motivation

  • This Paper’s Key Insight

The many available short-run outcomes are noisy measures of some underlying set of latent surrogates which are never observed.

  • Proposed Solution
    • Formalize as a latent variable problem
    • Use regularized regression (Ridge, Lasso, PLS) to construct a surrogate index
    • Theoretical analysis shows: Bias of Ridge regression decreases as more proxies are added
  • Contributions
    1. Formalization as latent variable regression with measurement error
    2. Closed-form bias expressions for Ridge regression
    3. Numerical simulations comparing estimators
    4. Empirical application to California GAIN experiment

What is a Surrogate? (Medical Origins)

Definition (Prentice, 1989): A surrogate endpoint is a biomarker that can substitute for a clinical endpoint — it must fully capture the treatment’s effect on the outcome of interest.

Classic Example: HIV/AIDS Trials

  • True endpoint: Survival / disease progression (takes years)
  • Surrogate: CD4 cell count (measurable in weeks)
  • If treatment only affects survival through CD4 count → valid surrogate

The Surrogacy Criterion: \[Y \perp\!\!\!\perp W \mid S\]

Treatment \(W\) affects outcome \(Y\) only through the surrogate \(S\).

Problem: This is a strong assumption! Often violated in practice.

The Surrogate Index Approach

Key Papers:

  • Athey, Chetty, Imbens & Kang (2019): “The Surrogate Index”
  • Chen & Ritzwoller (2023): Semiparametric estimation
  • Kallus & Mao (2020): From observational surrogates

The Idea:

Instead of a single surrogate, construct a surrogate index — a weighted combination of multiple short-term outcomes:

\[\tilde{S} = \sum_{j=1}^{k} \alpha_j P_j\]

Why “Index”?

  • Similar to a “propensity score” or “prognostic score”
  • Reduces dimensionality: \(k\) proxies → 1 index
  • The index should predict the long-term outcome \(Y\)

Surrogate Index: The Two-Sample Setup

Why Two Samples?

  • Experiments are expensive and time-limited
  • Long-term outcomes take years to observe
  • But: Observational data with \((P, Y)\) may be abundant

The Classic Surrogate Index Estimator:

  1. Observational data \((P_i, Y_i)\): Regress \(Y\) on \(P\) to get \(\hat{\alpha}\) \[\hat{\alpha} = \arg\min_\alpha \sum_i (Y_i - P_i' \alpha)^2\]

  2. Experimental data \((W_i, P_i)\): Estimate \(\hat{\tau}_P = \bar{P}_{W=1} - \bar{P}_{W=0}\)

  3. Combine: \[\hat{\tau}_{\text{long-term}} = \hat{\tau}_P' \hat{\alpha}\]

This is valid if the surrogacy criterion holds: \(Y \perp\!\!\!\perp W \mid P\)

The Problem This Paper Addresses

Classic Surrogate Index assumes:

  • We observe “true” surrogates \(S\) that fully mediate effects
  • Or: The observed proxies \(P\) themselves satisfy surrogacy

Reality in Digital Platforms:

  • We observe many short-term metrics (clicks, views, add-to-carts, …)
  • These are noisy measures of underlying user state
  • No single metric is a “true” surrogate
  • \(k\) (observed proxies) \(\gg\) \(p\) (latent surrogates)

This Paper’s Contribution:

Formalize the setting where observed proxies are noisy measurements of latent surrogates, and show how regularized regression can leverage many noisy proxies to reduce bias.

Problem Setup: The Causal Model

Notation:

  • \(W\) : Binary treatment (e.g., new recommendation algorithm)
  • \(S \in \mathbb{R}^p\) : Unobserved \(p\)-dimensional surrogate/state
  • \(P \in \mathbb{R}^k\) : Observed \(k\)-dimensional vector of noisy proxies
  • \(Y\) : Scalar long-term outcome

Core Relationships:

  1. First Stage (Treatment → Surrogate): \[S(w) = \gamma w + \epsilon_S\]

  2. Proxy Generation (Surrogate → Proxies): \[P(w) = L \cdot S(w) + E\] where \(L \in \mathbb{R}^{k \times p}\) is a loading matrix, \(E\) is noise

  3. Second Stage (Surrogate → Outcome): \[Y(w) = S(w)' \beta + \eta\]

The Causal Graph

Key Features:

  • \(S\) is unobserved (gray node)
  • Treatment \(W\) only affects \(Y\) through \(S\) (surrogacy)
  • Proxies \(P\) are noisy measures of \(S\)
  • Number of proxies \(k\) can be much larger than number of surrogates \(p\)

Target Estimand: \[\tau^* = \mathbb{E}[Y(1) - Y(0)] = \gamma' \beta\]

Economic Interpretation

Random Utility Framework

  • Consumer \(i\) has preference state \(S_i \in \mathbb{R}^p\) (e.g., quality perception, price sensitivity, brand affinity)
  • Treatment shifts preferences: \(S_i = \bar{S} + \gamma W_i + \tilde{\epsilon}_{S,i}\)
  • Observed behaviors are choice outcomes: \[P_i = L \cdot S_i + E_i\]
    • \(L\) captures how preferences manifest in behaviors
    • \(E_i\): idiosyncratic variation (measurement error, contextual factors)
  • Long-term value aggregates consumer state: \[Y_i = S_i' \beta + \eta_i\]

Data Structure

Two Separate Datasets:

Dataset Size Observations Purpose
Experimental \(\mathcal{D}_E\) \(N_e\) \((W_i, P_i)\) Estimate treatment effects on proxies: \(\tau_P = \mathbb{E}[P|W=1] - \mathbb{E}[P|W=0]\)
Observational \(\mathcal{D}_O\) \(N_o > N_e\) \((P_i, Y_i)\) Estimate relationship between proxies and outcome

The experimental data gives us treatment effects on proxies, but we never observe \(W\) and \(Y\) jointly!

The Feasible Estimator

Two-Stage Approach:

  1. Stage 1: Estimate treatment effect on proxies from \(\mathcal{D}_E\): \[\hat{\tau}_P = \bar{P}_{W=1} - \bar{P}_{W=0}\]

  2. Stage 2: Regress \(Y\) on \(P\) in \(\mathcal{D}_O\) to get coefficients \(\hat{\alpha}\): \[\hat{\alpha}_\lambda = \left(\sum_i P_i P_i' + \lambda I_k\right)^{-1} \sum_i P_i Y_i\]

  3. Combine: The long-term treatment effect estimator: \[\hat{\tau}_\lambda = \hat{\tau}_P' \hat{\alpha}_\lambda = \sum_{j=1}^{k} \hat{\tau}_j \hat{\alpha}_{\lambda,j}\]

The Identification Challenge

Without Measurement Error (\(E = 0\)):

  • Proxies \(P = L \cdot S\) satisfy the surrogacy condition
  • OLS regression of \(Y\) on \(P\) identifies \((L')^+ \beta\)
  • \(\tau_P\) identifies \(L \gamma\)
  • Hence: \((L\gamma)'(L')^+ \beta = \gamma' \beta = \tau^*\) ✓

With Measurement Error: The feasible estimator is biased due to attenuation!

Central Questions:

  1. How large is the attenuation bias when proxies are noisy?
  2. Does having more proxies \(k\) reduce this bias?
  3. How should we estimate \(\alpha\) when \(P\) is high-dimensional and noisy?

Intuition: Scalar Surrogate with Two Proxies

Simple Model: \[S = \tau_S W + \epsilon_S, \quad P_1 = S + \epsilon_1, \quad P_2 = S + \epsilon_2\] \[Y = \beta S + \eta\]

Regression of \(Y\) on \((P_1, P_2)\) gives:

\[\alpha_1 = \beta \frac{\sigma_S^2 \sigma_2^2}{\sigma_S^2 \sigma_1^2 + \sigma_S^2 \sigma_2^2 + \sigma_1^2 \sigma_2^2}\]

Key Insights:

  1. \(\frac{\alpha_1}{\alpha_2} = \frac{\sigma_2^2}{\sigma_1^2}\) — Proxy with less noise gets larger weight
  2. \(\alpha_1 + \alpha_2 < \beta\) — Total effect is attenuated

\[\text{plim}(\hat{\tau}_P' \hat{\alpha}) = \tau_S (\alpha_1 + \alpha_2) < \tau_S \beta = \tau^*\]

Many Proxies Reduce Bias!

Extend to \(k\) noisy proxies: \[P_j = S + \epsilon_j, \quad j = 1, \ldots, k\]

with i.i.d. measurement errors \(\text{Var}(\epsilon_j) = \sigma_E^2\)

Result: The sum of regression coefficients is:

\[\sum_{j=1}^{k} \alpha_j = \beta \cdot \frac{k \sigma_S^2}{k \sigma_S^2 + \sigma_E^2}\]

As \(k \to \infty\): \[\lim_{k \to \infty} \sum_{j=1}^{k} \alpha_j = \beta\] With many proxies, we can average out the measurement error!

Ridge Regression for High-Dimensional Setting

The Ridge Estimator: \[\hat{\alpha}_\lambda = \left(\sum_i P_i P_i' + \lambda I_k\right)^{-1} \sum_i P_i Y_i\]

Why Ridge?

  • Proxies are highly collinear (all measure same underlying \(S\))
  • OLS is unstable in high dimensions
  • Ridge shrinks coefficients systematically

Final Estimator: \[\hat{\tau}_\lambda = \hat{\tau}_P' \hat{\alpha}_\lambda\]

Asymptotic Bias of Ridge

Under homoskedasticity (\(\Sigma_S = \sigma_S^2 I_p\), \(\Sigma_E = \sigma_E^2 I_k\)):

General Form: \[\text{Bias}_\lambda = \gamma' \left[ L' (L \Sigma_S L' + \Sigma_E + \lambda I_k)^{-1} L \Sigma_S - I_p \right] \beta\]

With Balanced Loadings (\(L'L = c \cdot I_p\), where \(c = k/p\)):

\[\text{Bias}_\lambda = -\left(\frac{\sigma_E^2 + \lambda}{c \sigma_S^2 + \sigma_E^2 + \lambda}\right) \tau^*\]

Interpretation:

  • Always attenuated towards zero
  • Bias proportional to true effect \(\tau^*\)
  • Larger \(c\) (more proxies per surrogate) → smaller bias
  • Higher \(\lambda\) → larger bias

Bias-Variance Tradeoff

Asymptotic Mean Squared Error (AMSE):

\[\text{AMSE}(\hat{\tau}_\lambda) = \underbrace{\left(\frac{\sigma_E^2 + \lambda}{c \sigma_S^2 + \sigma_E^2 + \lambda}\right)^2 (\tau^*)^2}_{\text{Squared Bias}} + \underbrace{\frac{\sigma_\eta^2 \cdot c \cdot \|\gamma\|^2}{n} \cdot \frac{c \sigma_S^2 + \sigma_E^2}{(c \sigma_S^2 + \sigma_E^2 + \lambda)^2}}_{\text{Variance}}\]

The Tradeoff:

\(\lambda\) Bias Variance
↑ Increase ↑ Increases ↓ Decreases
↓ Decrease ↓ Decreases ↑ Increases

Optimal Regularization: \[\lambda^* = \frac{\sigma_\eta^2 \|\gamma\|^2 (c \sigma_S^2 + \sigma_E^2)}{n (\tau^*)^2 \sigma_S^2} - \sigma_E^2\]

\(\Rightarrow\) Justifies using cross-validation in practice

Variance Estimation & Inference

Delta-Method Decomposition: \[\widehat{\text{Var}}(\hat{\tau}_\lambda) \approx \hat{\alpha}_\lambda^\top \widehat{\text{Var}}(\hat{\tau}_P) \hat{\alpha}_\lambda + \hat{\tau}_P^\top \widehat{\text{Var}}(\hat{\alpha}_\lambda) \hat{\tau}_P\]

First-Stage Variance (Experimental): \[\widehat{\text{Var}}(\hat{\tau}_P) = \frac{\hat{\Sigma}_{P|W=1}}{n_1} + \frac{\hat{\Sigma}_{P|W=0}}{n_0}\]

Second-Stage Variance (Observational Ridge): \[\widehat{\text{Var}}(\hat{\alpha}_\lambda) = A_\lambda \left(X^\top \text{diag}(\hat{e}_1^2, \ldots, \hat{e}_{n_O}^2) X\right) A_\lambda\]

where \(A_\lambda = (X^\top X + \lambda I)^{-1}\)

Confidence Intervals: \(\hat{\tau}_\lambda \pm z_{1-\alpha/2} \cdot \widehat{\text{SE}}(\hat{\tau}_\lambda)\)

Numerical Experiments: Setup

Data Generating Process:

  • \(n = 5000\) observations
  • \(p = 5\) true surrogates
  • \(k = 30\) observed proxies (6 per surrogate)
  • \(S \sim N(0, \Sigma_S) + \tau_S W\) with \(\tau_S = 0.5\)
  • \(\beta = [1, 1/2, 1/3, 1/4, 1/5]'\) (decaying importance)
  • \(P = S \cdot L + E\) with compound symmetry noise

Methods Compared:

  1. Oracle: Direct regression \(Y \sim W\) (infeasible)
  2. OLS Screening (L0): Select top 10 proxies by \(|\alpha_j|\)
  3. Lasso (L1): Cross-validated sparse regression
  4. Ridge (L2): Cross-validated regularized regression
  5. PLS: Partial Least Squares dimensionality reduction

Numerical Results: Scalar Surrogate

All methods improve with more proxies. Ridge and PLS perform best, approaching the oracle as \(k\) increases.

Numerical Results: Vector Surrogate

OLS Screening deteriorates with more proxies due to model selection errors in high dimensions!

Numerical Results: Increasing Surrogates

As \(p\) grows with fixed proxies per surrogate, all methods face persistent bias — but Ridge still performs best.

Why Does OLS Screening Fail?

The Problem:

  • As \(k\) increases, more proxies → more chances for spurious correlations
  • OLS greedily selects proxies with largest (potentially spurious) coefficients
  • Model selection mistakes introduce bias

Mathematical Intuition:

  • In high dimensions, some noise terms will correlate with \(Y\) by chance
  • OLS has no mechanism to filter these out

Why Regularization Helps:

  • Ridge shrinks all coefficients towards zero
  • Effectively averages across many signals
  • Filters out noise, recovers reliable surrogate measure
  • No binary in/out decisions that can go wrong

Empirical Application: California GAIN

Background:

  • California GAIN (Greater Avenues for Independence) experiment
  • Job assistance program for welfare recipients (1980s)
  • Data: Employment, earnings, aid receipt over 36 quarters (9 years)

Setup:

  • Long-term outcome: Employment rate in last year
  • Proxies: Employment, earnings, aid receipt in earlier quarters

Question: Can we use early outcomes to predict long-term effects?

GAIN Results: Ridge Estimator

GAIN Results: Key Findings

Ridge Surrogate Index:

  • Gets closer to true estimate with more periods (16 → 32 quarters)
  • Improves with more measurement types (employment → employment + earnings + aid)
  • Confidence intervals include true effect

OLS Screening:

  • Does not improve with additional surrogates
  • Stays biased even with more data
  • Confirms simulation findings

The Ridge estimator successfully leverages multiple noisy proxies to approach the true long-term treatment effect!

Connection to Double Machine Learning

What DML Does:

  • Handles high-dimensional nuisance parameters via cross-fitting
  • Uses Neyman orthogonality to achieve \(\sqrt{n}\)-consistency
  • Targets: \(\theta = \mathbb{E}[Y(1) - Y(0)]\) with observed \((W, X, Y)\)

How This Paper Differs:

Aspect DML Surrogate Index
Data \((W_i, X_i, Y_i)\) joint Two samples: \((W, P)\) and \((P, Y)\)
Nuisance \(\mathbb{E}[Y|X]\), \(\mathbb{E}[W|X]\) \(\mathbb{E}[Y|P]\)
Challenge Selection bias Never observe \((W, Y)\) jointly
Regularization For nuisance estimation Core of identification strategy

In DML, regularization is a tool for nuisance estimation. Here, regularization is fundamental to averaging out measurement error in proxies.

Why Not Just Apply DML?

The Fundamental Problem:

In DML, we need observations \((W_i, X_i, Y_i)\) to estimate: \[\theta = \mathbb{E}\left[\frac{W - e(X)}{e(X)(1-e(X))}(Y - \mu(X))\right]\]

In Long-Term Settings:

  • Experiment runs for weeks/months
  • Long-term outcome \(Y\) observed years later
  • By the time \(Y\) is observed, the experiment is long over
  • We never see \((W_i, Y_i)\) in the same dataset!

The Surrogate Approach:

  • Uses observational data \((P, Y)\) to learn the \(P \to Y\) relationship
  • Applies this to experimental \((W, P)\) data
  • Key assumption: Surrogacy (or noisy surrogacy in this paper)

Measurement Error Perspective

For DML Practitioners — A Familiar Frame:

Think of this as an errors-in-variables problem:

  • We want to regress \(Y\) on “true” surrogate \(S\)
  • But we only observe noisy proxies \(P = LS + E\)
  • Classic attenuation bias: coefficients shrink toward zero

The Key Insight (related to factor models):

\[P = L \cdot S + E \quad \text{where } k > p\]

  • \(L \in \mathbb{R}^{k \times p}\): factor loadings
  • \(S \in \mathbb{R}^p\): latent factors (true surrogates)
  • \(E \in \mathbb{R}^k\): idiosyncratic noise

With many proxies (\(k \to \infty\)):

  • We can “average out” the measurement error
  • Regularization (Ridge) provides stable averaging
  • Bias shrinks as \(c = k/p\) increases

Discussion: Method Comparison

Method Mechanism Pros Cons
Ridge \(L_2\) shrinkage Closed-form bias analysis, stable Keeps all predictors
Lasso \(L_1\) shrinkage Sparse solutions Selection can be unstable
PLS Dimensionality reduction Targets covariance with \(Y\) Less interpretable
OLS Screening Hard selection Simple Fails in high dimensions

Paper’s Focus on Ridge:

  • Provides clearest theoretical insight into bias-variance tradeoff
  • Analytical tractability allows closed-form expressions
  • All regularized methods outperform naive screening

Conclusions

  1. The Problem: Estimating long-term treatment effects with many noisy short-term proxies

  2. The Solution: Formalize as latent variable regression; use regularized methods

  3. Key Theoretical Result: \[\text{Bias}_\lambda = -\left(\frac{\sigma_E^2 + \lambda}{c \sigma_S^2 + \sigma_E^2 + \lambda}\right) \tau^*\]

    • Bias decreases as \(c = k/p\) (proxies per surrogate) increases

  4. Practical Implications:

    • Use Ridge/Lasso/PLS instead of ad-hoc proxy selection
    • More proxies = better (with regularization)
    • Cross-validation for tuning \(\lambda\)

What About Orthogonalization?

A Natural Question for DML Practitioners:

Could we construct a Neyman-orthogonal moment for the surrogate index?

The Challenge:

  • Standard orthogonalization requires \((W, Y)\) in same sample
  • Here: nuisance \(\alpha\) estimated on different sample than \(\tau_P\)
  • Independence of samples already provides some robustness

Recent Related Work:

  • Chen & Ritzwoller (2023): Semiparametric surrogate index with debiasing
  • Athey et al. (2019): Focus on valid inference rather than orthogonalization

Open Question: Can DML-style orthogonalization improve upon the simple plug-in estimator \(\hat{\tau} = \hat{\tau}_P' \hat{\alpha}\)?

Appendix

Appendix: Derivation of Asymptotic Bias

Starting from the general bias expression:

\[\text{Bias}_\lambda = \gamma' \left[ L' (L \Sigma_S L' + \Sigma_E + \lambda I_k)^{-1} L \Sigma_S - I_p \right] \beta\]

Under homoskedasticity (\(\Sigma_S = \sigma_S^2 I_p\), \(\Sigma_E = \sigma_E^2 I_k\)) and using SVD \(L = U D V'\):

Let \(A = \sigma_S^2 U D^2 U' + (\sigma_E^2 + \lambda) I_k\)

Using block structure: \(I_k = UU' + U_\perp U_\perp'\)

\[A^{-1} = U(\sigma_S^2 D^2 + (\sigma_E^2 + \lambda) I_p)^{-1} U' + \frac{1}{\sigma_E^2 + \lambda} U_\perp U_\perp'\]

Appendix: Spectral Bias Decomposition

With SVD \(L = UDV'\) and rotated coordinates \(\tilde{\gamma} = V'\gamma\), \(\tilde{\beta} = V'\beta\):

\[\tau_\lambda = \sum_{j=1}^{p} \frac{\sigma_S^2 d_j^2}{\sigma_S^2 d_j^2 + \sigma_E^2 + \lambda} \tilde{\gamma}_j \tilde{\beta}_j\]

Interpretation:

  • Each latent direction \(j\) has shrinkage factor \(\kappa_j(\lambda) = \frac{\sigma_S^2 d_j^2}{\sigma_S^2 d_j^2 + \sigma_E^2 + \lambda}\)
  • Directions with small \(d_j^2\) (weakly measured) are attenuated more
  • Adding proxies that increase smallest \(d_j^2\) helps most

Appendix: Variance Derivation

Asymptotic variance of \(\hat{\tau}_\lambda\):

\[\text{Var}_{asy}(\hat{\tau}_\lambda) = \frac{1}{n} \tau_P' \text{AVar}(\sqrt{n}(\hat{\alpha}_\lambda - \alpha_\lambda)) \tau_P\]

Using sandwich formula and balanced loadings:

\[\text{Var}_{asy}(\hat{\tau}_\lambda) = \frac{\sigma_\eta^2}{n} \cdot c \cdot \|\gamma\|^2 \cdot \frac{c \sigma_S^2 + \sigma_E^2}{(c \sigma_S^2 + \sigma_E^2 + \lambda)^2}\]
