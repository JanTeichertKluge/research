Evaluations on buybox data, embedding dimensions and significant heterogeneous effects

What has changed compared to the JASA version?

  • The Treatment Variable In the submitted JASA Version, we used the NEW Price (labeled as \(P_t\)) as Treatment, now we use the BUY_BOX Price (labeled as \(P^{bb}_t\)) as Treatment. For that we had to repull the data from keepa and recreate the dataset.

  • The time gap between periods The time gap between the two periods has been removed (7 days gap in the JASA version). Now each time-dependent variable \(X_t\) is calculated on the basis of the previous 28 days, so that \(X_{t-1}\) is adjacent to the “oldest” day of \(X_t\).

    • That increased the sample size.

  • Training Procedure
    At the beginning of the year, we experimented with hyperparameter optimization within the multimodal neural network using Ray-Tune. The following search space was run through:

      search_space = {
    "embedding_dim": tune.choice([None, 256, 512, 1024]),
    "fusion_head": tune.choice([[64], [128], [256, 128], [512, 256, 128]]),
    "lr": tune.loguniform(1e-4, 1e-1),
    "batch_size": tune.choice([16, 32]),
}

Changes in the distribution of the treatment variable

Observations

  • The hyperparameter tuning did lead to a slight improvement in the models predictive performance.
    • For the BUY_BOX and \(0\) Days Gap Setting, the optimal embedding dimension was selected to \(512\).
  • It seems that the models embedding dimension (e.g. using the cross-attention-block if there was a specific dimension defined) has a significant impact on the lower dimensional projections of the embeddings used for clustering.

Changes on the ATE Estimation

  • JASA Version (using NEW Price, \(7\) Days Gap): \(ATE \approx −0.53\)
  • New Setting A (using BUY_BOX Price, \(0\) Days Gap, tuned (using cross-attention)): \(ATE \approx −0.75\)
  • New Setting A (using BUY_BOX Price, \(0\) Days Gap, same hyperparams as in JASA): \(ATE \approx −0.75\)
  • New Setting B (using BUY_BOX Price, \(7\) Days Gap, tuned (using cross-attention)): \(ATE \approx −0.75\)
  • New Setting B (using BUY_BOX Price, \(7\) Days Gap, same hyperparams as in JASA): \(ATE \approx −0.75\)
